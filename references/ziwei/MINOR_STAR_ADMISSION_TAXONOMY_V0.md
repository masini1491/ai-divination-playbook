Authority：`REFERENCE-ONLY / RESEARCH TAXONOMY / NOT PRODUCTION-ROUTABLE`

```text
minor/auxiliary stars as one admission batch     REJECTED

```

## Why taxonomy precedes claim expansion

Modern implementations expose dozens to more than one hundred non-major-star identities. Treating all of them as one “minor-star corpus” would mix strongly source-backed assistants, high-impact traditional modifiers, modern or lineage-specific auxiliaries, symbolic long-tail stars, and cycle/flow stars whose identity depends on temporal context.

Therefore admission priority is based on evidence responsibility and semantic impact, not implementation availability alone.

## Tier M0 — source/calculation foundation already strong

```text
左輔
右弼
文昌
文曲
```

Current research already records multi-engine placement convergence and rule-specific primary-source support for these selected assistants. This taxonomy does **not** automatically admit new interpretation core claims; it marks them as the first eligible auxiliary subjects when a dedicated source-normalized claim batch is justified.

## Tier M2 — long-tail auxiliary candidates

Examples include symbolic/social/romance and specialist stars such as 紅鸞、天喜、天姚、天刑、三台、八座、恩光、天貴、龍池、鳳閣 and similar long-tail identities exposed by implementations.

```text
priority = later
admission = DEFER
reason = lower first-pass leverage + larger lineage/source normalization burden
```

An implementation exposing a star does not establish its universal placement or interpretation authority.

## Tier M3 — cycle / flow / temporal stars

Cycle families such as 博士十二神、將前十二神、歲建十二神 and flow-prefixed variants are not treated as ordinary natal minor stars.

```text
owner = temporal/dynamic research
admission = DEFER
```

They require temporal scope, boundary/profile identity and dynamic calculation provenance before interpretation admission.

## Admission gate

A future auxiliary-star claim batch should require, per subject:

1. stable canonical identity / aliases;
2. placement rule and profile scope;
3. source or named-tradition evidence;
4. bounded semantic core/conditional claim;
5. conflict handling;
6. no automatic promotion from engine availability;
7. explicit distinction between natal and temporal identities.
